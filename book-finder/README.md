# SOCRP Web Client

This Vite + React single-page application powers the SOCRP membership experience for members, administrators, and employers. It
communicates with the Python backend exposed under `VITE_API_URL` (defaults to `http://localhost:8000`).

## Available Views
- **Landing** – overview, feature matrix, quick navigation.
- **Registration** – member sign-up with photo/resume uploads.
- **Verify** – paste the verification token generated by the backend.
- **Member Workspace** – authenticated editing of personal data, education, experience, skills, languages, resume, photo, and
  share links.
- **Admin Control Center** – dashboard metrics, member table, full profile overrides, and block/unblock controls.
- **Share View** – accessible via `/share/{token}` for employers.

## Getting Started
```bash
npm install
npm run dev
```
The dev server runs at `http://localhost:5173`. Set `VITE_API_URL` in a `.env` file if your backend runs elsewhere.

## Build
```bash
npm run build
```
